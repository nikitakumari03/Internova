# Internova

### Internship Search & Application Platform

Internova is a web-based internship platform designed to help students search for internship opportunities and apply for them easily.

## Features

- 🔍 Search internships by role or skill
- 📍 Filter internships by location
- 📄 View complete internship details
- 📝 Online internship application
- 📎 Resume upload in PDF, DOC, and DOCX formats
- ✅ Application form validation
- 👤 Admin signup and secure login
- 🔐 Password reset functionality
- 📊 Admin dashboard
- 🔎 Search applications
- 👁️ View applicant details
- 📥 Download applicant resumes
- 🗑️ Delete applications
- 🚪 Secure admin logout
